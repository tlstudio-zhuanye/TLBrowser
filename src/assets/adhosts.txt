# TL 浏览器 · 内置拦截规则
#
# 三种写法，一行一条，# 开头是注释：
#   example.com    域后缀拦截（example.com 及其所有子域）
#   =ad            精确标签拦截（host 里任意一段正好等于 ad 就拦，例如 ad.foo.com）
#   +example.com   放行（优先于上面两种，用于「某个站被误拦了」）
#
# 只拦资源请求里的图片/脚本/样式/XHR/媒体/字体，**主文档永不拦截**——
# 这样最坏情况是页面少个组件，绝不会出现「点开就是一片白」。
# 想自己加规则：%LOCALAPPDATA%\TLSTUDIO\TLBrowser\adblock_user.txt，格式同上。
